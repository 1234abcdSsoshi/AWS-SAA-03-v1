# 先輩、AWSを教えてください！ 〜SAA-C03 リベンジ・レッスン〜

AWS Certified Solutions Architect – Associate（SAA-C03）の**再受験**に向けた、ストーリー型の学習アプリです。
入社2年目のインフラエンジニア「七瀬あかり」が、社内テクニカルインストラクター（TI）の「氷室レン」から2週間の特訓を受ける——というビジュアルノベル形式で、講義・クイズ・ハンズオン・模擬試験を進めます。

> 非公式の学習教材です（AWS とは関係ありません）。問題はすべてオリジナルで、実際の試験問題は含みません。

---

## 起動方法

- **いちばん簡単**：`index.html` をダブルクリック（Chrome / Edge 推奨）
- **ローカルサーバーで開く場合**（任意）：
  ```bash
  python -m http.server 8000
  # → http://localhost:8000 を開く
  ```

インストールやビルドは不要です。最初の画面で「タップしてはじめる」を押すと BGM が鳴ります（右上の 🔊 でミュート）。

| 機能 | 内容 |
|---|---|

| **学習記録** | 分野別の正答率と「コンピテンシーを満たしている／改善が必要」の判定、タスク別ヒートマップ、模擬試験の履歴 |
| **📝 メモ欄** | 全体ノート／表示中の問題・スライドごとのメモ／一覧。Markdown・JSON で書き出し・読み込み |

### おすすめの進め方
1. **はじめから** → プロローグの実力診断
2. 第1〜2章（得意分野の維持）→ 第3〜6章（弱点分野）を順に
3. 間違えた問題は、各問題の「📝 メモに追加」「💬 この問題を質問」で深掘り
4. 学習記録で弱い**タスク**を確認 →「このタスクを練習」
5. 最終章で模擬試験 → 結果に応じて「弱点集中モード」で仕上げ

## 質問チャットの設定（Claude API）

API キーがなくても、**オフラインモード**（用語集・スライド・問題のポイントから回答）で使えます。
詳しい対話をしたい場合は、Claude API キーを登録してください。

1. Claude Console（https://platform.claude.com/）で API キーを発行
2. アプリの **設定 → 質問チャット**（またはチャット欄の ⚙）でキーを登録
3. モデルを選択：`claude-opus-5-5`（既定・高精度）／`claude-sonnet-5-5`（高速・低コスト）／`claude-haiku-4-5`（最速）

補足：
- API 利用料はご自身の Anthropic アカウントに請求されます。
- キーはこのブラウザの中だけに保存され（「このタブだけ」も選べます）、`api.anthropic.com` 以外には送信されません。データのエクスポートにも含まれません。**共有 PC では保存しないでください。**
- Opus 5.5 / Sonnet 5.5 では、安全上の理由で回答が拒否された場合に自動で別モデルへ切り替える**サーバー側フォールバック**（`fallbacks: "default"`）を有効にしています。不要な場合は `js/panels/chat.js` の `buildParams` から外せます。
- ブラウザから直接 API を呼ぶため、同梱の `vendor/anthropic-sdk.min.js`（@anthropic-ai/sdk v0.131.0、MIT）を使用しています。社内プロキシで `api.anthropic.com` が遮断されている環境ではオフラインモードになります。
- 模擬試験の受験中は、試験問題についての質問はできません。

## 画像の作成（ChatGPT / Codex）

画像（立ち絵 17・顔アイコン 2・背景 10・イベント CG 10）は **[Codex.md](Codex.md)** の手順で ChatGPT / OpenAI Codex で作成してください。

- 保存先・ファイル名は `data/assets.js` と同じにします（例：`assets/images/characters/akari_smile.png`）。
- 画像がない間は、自動でプレースホルダー（シルエット・グラデーション）が表示されます。置くだけで差し替わります。
- **設定 → 画像アセット確認**（`index.html#assets`）で、そろっているかを確認できます。
- 全プロンプトは `assets/image-prompts.json`（`node tools/build-image-prompts.mjs` で再生成）。

画像が未作成の間は、ブラウザの開発者ツールのコンソールに画像の読み込みエラー（ERR_FILE_NOT_FOUND）が表示されますが、動作には影響しません。

## データの保存とプライバシー

- 学習記録・メモ・設定は、このブラウザの localStorage に保存されます（サーバーには送信されません）。
- **設定 → データ** でバックアップ（JSON）の書き出し・読み込み、全データの消去ができます。
- 受験結果の PDF に含まれる氏名・受験者 ID・登録番号・点数などの個人情報は、アプリのどこにも含めていません（ストーリーでも「あと一歩」とだけ表現しています）。
- フォルダを他の人と共有する場合は、プロジェクト直下の受験結果 PDF を含めないよう注意してください。

## 開発者向け

- `node tools/validate.mjs` … 問題・スライド・ラボ・台本・画像参照の整合性チェック（`--only=c3-storage` などで絞り込み）
- `index.html?selftest=1` … ブラウザ内セルフテスト（全画面の描画、全章の台本検証、全問の採点、全ラボの想定解、BGM/効果音のオフライン描画、メモ、オフラインチャットなど 46 項目）。結果は画面下部と `document.title`（`SELFTEST:PASS` / `SELFTEST:FAIL`）に表示
- 問題を追加するときは `docs/SPEC.md` の §4.1（スキーマと作問ルール）に従い、validate を通してください。
